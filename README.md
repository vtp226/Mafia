# ربات بازی «شهر مخفی» (نسخه‌ی پایتون)

همون بازی قبلی، این‌بار با پایتون و کتابخونه‌ی `python-telegram-bot`. نسخه‌ی
پایتون با **polling** کار می‌کنه (نه webhook)، یعنی:

- ✅ لازم نیست دامنه داشته باشی یا `setWebhook` بزنی
- ✅ لازم نیست هیچ سرویس کرون جدا (مثل cron-job.org) تنظیم کنی — بستن خودکار
  رأی‌گیری‌ها با یه job دوره‌ای داخل خودِ پروسه انجام می‌شه
- فقط کافیه کد رو رو Railway اجرا کنی و چندتا متغیر محیطی رو پر کنی

## فایل‌ها

| فایل | کار |
|---|---|
| `config.py` | خوندن تنظیمات از environment variables |
| `db.py` | اتصال به SQLite و ساخت جدول‌ها |
| `roles.py` | تعریف نقش‌ها + الگوریتم تخصیص رندوم درصدی |
| `game.py` | کل منطق بازی: ثبت‌نام، شروع، اقدام‌ها، رأی‌گیری، پایان بازی |
| `bot.py` | نقطه‌ی ورود — هندلرهای تلگرام + polling + جاب دوره‌ای |

## مراحل راه‌اندازی

### ۱. ساخت ربات و جمع‌کردن اطلاعات لازم
- از [@BotFather](https://t.me/BotFather) یه ربات بساز و توکنش رو بگیر (`BOT_TOKEN`).
- یوزرنیم ربات بدون `@` رو یادداشت کن (`BOT_USERNAME`).
- ربات رو **ادمین کانال** و **ادمین گروه**ت کن.
- آیدی عددی گروه رو بگیر (با @userinfobot یا مشابه) → `GROUP_ID`.
- آیدی کانال: اگه پابلیکه همون `@channel_username`، اگه پرایوته آیدی عددی `-100...` → `CHANNEL_ID`.
- آیدی عددی خودت (و هر ادمین دیگه) رو بگیر → `ADMIN_IDS` (با کاما جدا کن، مثلا `111,222`).

### ۲. آپلود روی گیت‌هاب
```bash
git init
git add .
git commit -m "اولین نسخه - پایتون"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
هیچ توکنی داخل کد نیست، همه‌چی از environment variables خونده می‌شه، پس امنه که ریپو پابلیک باشه.

### ۳. ساخت پروژه روی Railway
1. تو [railway.app](https://railway.app) با گیت‌هاب لاگین کن.
2. **New Project → Deploy from GitHub repo** → همین ریپو رو انتخاب کن.
   Railway خودش `Dockerfile` رو پیدا می‌کنه و می‌سازتش.
3. برو تب **Variables** و این‌ها رو وارد کن (طبق `.env.example`):
   - `BOT_TOKEN`
   - `BOT_USERNAME`
   - `CHANNEL_ID`
   - `GROUP_ID`
   - `ADMIN_IDS`
4. نیازی به فعال‌کردن Networking/دامنه نیست — این یه worker ساده‌ست، وب‌سرور نداره.

### ۴. اضافه‌کردن Volume برای دیتابیس (مهم!)
بدون این، هر بار Railway دوباره دیپلوی کنه بازی و بازیکنا پاک می‌شن.
1. تو پروژه: **Settings → Volumes → New Volume**
2. Mount path: `/app/data`

همین! بعد از دیپلوی، لاگ‌ها رو چک کن — باید ببینی «ربات با polling شروع به کار کرد.»
از این لحظه ربات فعاله و منتظر پیام از تلگرامه، بدون هیچ مرحله‌ی اضافه‌ای.

## دستورات ادمین (فقط برای `ADMIN_IDS`، در پیوی ربات)
- `/newgame` — دور جدید بازی می‌سازه و لینک ثبت‌نام رو تو گروه پست می‌کنه
- `/startgame` — ثبت‌نام رو می‌بنده، نقش‌ها رو پخش می‌کنه و بازی رو شروع می‌کنه
- `/endgame` — بازی جاری رو دستی تموم می‌کنه
- `/status_admin` — وضعیت سریع بازی

## جریان بازیکن
همون جریان نسخه‌ی قبلی: کلیک روی دکمه‌ی ورود در گروه → چک عضویت کانال/گروه →
انتخاب اسم مستعار → بعد از `/startgame` نقش خصوصی می‌گیره → پیام‌های معمولی به
پیوی ربات با اسم مستعار توی کانال پست می‌شن → اقدام‌ها و رأی‌گیری با دکمه.

## تست لوکال (اختیاری)
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # و مقادیرش رو پر کن
python bot.py
```
